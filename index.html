01 / About

From infrastructure to the interface.

I work across the complete web application lifecycle: designing and implementing user-facing experiences, integrating application services, containerizing workloads, and operating Linux-based production environments. My day-to-day stack spans Next.js, Nuxt.js, ASP.NET Core, Laravel, Docker, Podman, and modern headless CMS platforms. Alongside engineering, I contribute to software localization on Crowdin, with a focus on Persian-speaking users.

06 / Delivery workflow

A complete path from design to production

01 / ARCHITECT

Plan the system

Map infrastructure, select the right stack, and define deployment targets — data models, content structure, and hosting requirements before the first commit.

02 / BUILD

Develop the product

Write frontend and backend code with clean, maintainable patterns — component-driven UI, typed API contracts, and reviewable commits.

03 / CONTAINERIZE

Prepare deployment

Package with Docker or Podman, write Compose files, document environment variables and volumes, and validate in staging.

04 / SHIP & MONITOR

Operate and improve

Deploy via 1Panel / Coolify, wire reverse proxies and SSL/TLS, tune SEO and performance, and monitor logs, uptime, and backups.
